# StayNest PG Finder
Two-page responsive Bootstrap 5.3 site. `index.html` includes a carousel, filter panel, six sample listings and Why choose us. `listings.html` presents the six listings. Both pages share `custom.css` and a common navbar/footer.

Bootstrap is loaded from the jsDelivr CDN, so internet access is required for its styles and responsive navbar.

Test both pages at 360px, 768px, and 1200px. Capture your own browser screenshots `index_360.png` and `listings_360.png` after checking no horizontal overflow.

Create public GitHub repository `pg-finder-site` and push this folder. Suggested commit: `Integrate PG finder site`.
