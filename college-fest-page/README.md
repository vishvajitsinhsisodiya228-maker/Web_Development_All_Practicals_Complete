# Udaan College Fest
Responsive college-fest page demonstrating semantic HTML, external CSS, selectors, box model, positioning, Flexbox, Grid, and max-width media queries.

Test with Chrome DevTools device toolbar at 360px, 768px, and 1200px. Save your own screenshots as `before_responsive.png` (before media queries) and `after_responsive.png` (after media queries).

Create public GitHub repository `college-fest-page`, then:
`git init`
`git add .`
`git commit -m "Build responsive college fest page"`
`git branch -M main`
`git remote add origin YOUR_REPOSITORY_URL`
`git push -u origin main`
