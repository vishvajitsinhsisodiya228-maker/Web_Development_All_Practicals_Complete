# Bright Path Tuition Classes
Open `index.html` in a browser. Pages: Home, Enquiry, Faculty. The class illustration `class_photo.jpg` is an original drawing generated for this project.

The enquiry form uses native HTML validation. For the required screenshot, enter fictional details only (for example, Aarya Demo, demo.parent@example.com, 9876543210, age 14), submit, and capture the address bar as `enquiry_submitted.png`.

GitHub: create public repo `tuition-class-site`; run `git init`, `git add .`, `git commit -m "Make site semantic"`, add your repository URL as `origin`, then `git push -u origin main`.
