# Web Basics Lab — DOM practical

## Task 1: Live DOM edit
1. Open https://example.com in Chrome.
2. Press F12 and select Elements.
3. Expand `html > body`; double-click the `h1` text and replace it with `Bright Path Tuition Classes`.
4. Edit the first paragraph to: `Bright Path Tuition Classes helps students build strong concepts through patient teaching, regular practice, and personal guidance.`
5. In the Styles pane, add `background-color: #eaf2ff;` to `body`.
6. Capture the browser with DevTools visible and save it as `dom_edit.png` in this folder BEFORE reloading.

## Task 2: DOM tree
`dom_tree.txt` is a starter transcription of the common example.com structure. Browser DOM can change; expand the live Elements tree and adjust the file if your browser shows additional tags. List every occurrence, indented by two spaces per level.

## Task 3–4: Draw.io
Open `browser_flow.drawio` in https://app.diagrams.net and choose Device if prompted. It has two pages: Browser Flow and Front and Back. Save any edits locally.

## GitHub
Create a public repository named `web-basics-lab`, then from this folder run:
`git init`, `git add .`, `git commit -m "Add DOM practical files"`, `git branch -M main`, `git remote add origin YOUR_REPOSITORY_URL`, `git push -u origin main`.

Note: `dom_edit.png` must be captured from your own live browser because this package cannot interact with your local Chrome DevTools session.
