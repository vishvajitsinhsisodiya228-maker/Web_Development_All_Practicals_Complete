WEB DEVELOPMENT PRACTICALS — COMPLETE STARTER PACKAGE
=====================================================

Folders included:
1. web-basics-lab       — DOM practical notes, DOM tree text, 2-page Draw.io file
2. tuition-class-site   — Home, enquiry form, faculty pages, CSS, original class illustration
3. college-fest-page    — Semantic HTML, pass cards, positioning, Flexbox, Grid, responsive CSS
4. pg-finder-site       — Bootstrap PG finder with Home + Listings pages and custom.css
5. gym-landing-page     — Responsive gym landing page with plans, timetable and enquiry form

HOW TO OPEN
- Extract the ZIP.
- Open each folder in VS Code or Eclipse (as a web project), or double-click its index.html.
- Bootstrap projects need an internet connection for the CDN.
- Draw.io file can be opened at https://app.diagrams.net.

IMPORTANT HONEST LIMITATIONS
- Browser DevTools screenshots cannot be captured from your local Chrome session by this package. Follow each folder's README and save the specifically named screenshots yourself.
- GitHub repositories are not created/pushed automatically. You must create the public repositories in your own GitHub account and run the commands in the README.
- `dom_tree.txt` is a starter transcription; verify the exact live DOM in your browser because website markup can change.

GITHUB QUICK STEPS (repeat for each folder)
1. Create a new PUBLIC repository with the exact name listed in that folder's README.
2. Open terminal inside that project folder.
3. Run:
   git init
   git add .
   git commit -m "Initial practical submission"
   git branch -M main
   git remote add origin https://github.com/YOUR-USERNAME/REPOSITORY.git
   git push -u origin main
